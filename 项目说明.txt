📊 推荐配置
-----------
硬件要求（服务器端）：
- GPU: NVIDIA RTX 2060 或更高（6GB+ 显存）
- RAM: 16GB+
- 硬盘: 20GB+ 可用空间

推荐模型（RTX 2060 6GB）：
- qwen3:8b        → 中文对话优秀（5.2 GB）
- gemma3:4b       → 速度快（3.3 GB）
- deepseek-r1:7b  → 代码/推理强（4.5 GB）

🚀 快速命令
-----------
# 下载模型
ollama pull qwen3:8b

# 运行模型
ollama run qwen3:8b

# 查看模型
ollama list

# 查看运行中的模型
ollama ps

# 删除模型
ollama rm qwen3:8b

# 测试服务器
curl http://localhost:11434

# 测试局域网访问
curl http://你的IP:11434

❓ 常见问题
-----------
Q: 手机无法访问？
A: 1. 确认同一 WiFi
   2. 使用 IP 而不是 localhost
   3. 检查防火墙
   4. 重启 Ollama

Q: 模型下载慢？
A: 1. 检查网络
   2. 先下载小模型测试
   3. 重启 Ollama 重试

Q: 显存不够？
A: 使用小模型（gemma3:4b 或 qwen3:3b）
